# செருகுநிரல்கள்

பயனர் உள்ளமைவில் `enabled: true` மூலம் TypeScript செருகுநிரலைச் செயல்படுத்தவும். இயல்பாக இறக்குமதியும் இயக்கமும் கட்டுப்படுத்தப்பட்ட Deno Worker-களில் நடைபெறும். Worker செருகுநிரல் கோப்பகத்தைப் படிக்கலாம்; `declaredEndpoints` இல் உள்ள ஹோஸ்ட் மற்றும் போர்ட்களுக்கு மட்டுமே இணைக்கலாம். கோப்பு எழுதுதல், செயல்முறைச் சூழலைப் படித்தல், துணைச் செயல்முறைகள், FFI மற்றும் கட்டுப்படுத்தப்பட்ட கணினித் தகவலுக்கான அணுகல் தடுக்கப்பட்டுள்ளன. `trust: trusted` என்பது Triggerfish செயல்முறையில் இறக்குமதியை அனுமதிக்கிறது. மேனிஃபெஸ்டும் `trusted` எனக் குறிப்பிட்டால் இயக்கியும் அதே செயல்முறையில் இயங்கும்.

```yaml
plugins:
  weather:
    enabled: true
    trust: sandboxed
```
