# الإضافات

فعّل إضافة TypeScript في إعدادات المستخدم عبر `enabled: true`. افتراضياً يعزل عامل Deno مقيّد استيراد الإضافة وتشغيلها. يمكنه قراءة مجلد الإضافة والاتصال بالمضيفين والمنافذ المحددة في `declaredEndpoints` فقط. لا يمكنه الكتابة أو قراءة بيئة العملية أو تشغيل عمليات فرعية أو استخدام FFI أو معلومات النظام المقيّدة. يسمح `trust: trusted` في الإعدادات بالاستيراد في عملية Triggerfish، ويعمل المنفّذ فيها إذا أعلن البيان الثقة أيضاً.

```yaml
plugins:
  weather:
    enabled: true
    trust: sandboxed
```
