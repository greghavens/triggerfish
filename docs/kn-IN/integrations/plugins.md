# ಪ್ಲಗಿನ್‌ಗಳು

ಬಳಕೆದಾರ ಸಂರಚನೆಯಲ್ಲಿ `enabled: true` ಬಳಸಿ TypeScript ಪ್ಲಗಿನ್ ಸಕ್ರಿಯಗೊಳಿಸಿ. ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಆಮದು ಮತ್ತು ಕಾರ್ಯಗತಗೊಳಿಸುವಿಕೆ ನಿರ್ಬಂಧಿತ Deno Worker‌ಗಳಲ್ಲಿ ನಡೆಯುತ್ತವೆ. Worker ಪ್ಲಗಿನ್ ಡೈರೆಕ್ಟರಿಯನ್ನು ಓದಬಹುದು ಮತ್ತು `declaredEndpoints` ನಲ್ಲಿರುವ ಹೋಸ್ಟ್ ಮತ್ತು ಪೋರ್ಟ್‌ಗಳಿಗೆ ಮಾತ್ರ ಸಂಪರ್ಕಿಸಬಹುದು. ಫೈಲ್ ಬರೆಯುವುದು, ಪ್ರಕ್ರಿಯೆಯ ಪರಿಸರ ಓದುವುದು, ಉಪಪ್ರಕ್ರಿಯೆಗಳು, FFI ಮತ್ತು ನಿರ್ಬಂಧಿತ ಸಿಸ್ಟಮ್ ಮಾಹಿತಿ ನಿಷೇಧಿತ. `trust: trusted` ಸಂರಚನೆ Triggerfish ಪ್ರಕ್ರಿಯೆಯಲ್ಲಿ ಆಮದನ್ನು ಅನುಮತಿಸುತ್ತದೆ. ಮ್ಯಾನಿಫೆಸ್ಟ್ ಸಹ `trusted` ಎಂದರೆ ಕಾರ್ಯಗತಗೊಳಿಸುವಿಕೆಯೂ ಅಲ್ಲಿಯೇ ನಡೆಯುತ್ತದೆ.

```yaml
plugins:
  weather:
    enabled: true
    trust: sandboxed
```
